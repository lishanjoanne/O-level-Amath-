Algebra

Polynomials & Partial Fractions

Identities, the Remainder & Factor Theorems, factorising/solving cubics, and splitting algebraic fractions into partial fractions.

Key Formulas

Division Algorithm
$$\text{dividend} = \text{divisor} \times \text{quotient} + \text{remainder}$$
The remainder's degree is always less than the divisor's.
Remainder Theorem
$$f(x) \div (ax+b) \implies \text{remainder} = f\!\left(-\tfrac{b}{a}\right)$$
Special case $x+b$: remainder $= f(-b)$.
Factor Theorem
$$ax+b \text{ is a factor of } f(x) \iff f\!\left(-\tfrac{b}{a}\right) = 0$$
Use this to hunt for a polynomial's linear factors.
Sum & difference of cubes
$$\begin{aligned} a^3+b^3 &= (a+b)(a^2-ab+b^2) \\ a^3-b^3 &= (a-b)(a^2+ab+b^2) \end{aligned}$$
Note the sign flips: opposite sign outside, always $+b^2$ inside.

Notes

Identities

$P(x) \equiv Q(x)$ means they're equal for every value of $x$ — not just solving for one $x$. To find unknown coefficients, either:

  • Substitute suitable values of $x$ — fastest when a value makes most terms vanish.
  • Compare coefficients of like powers of $x$ — more reliable when you need every unknown.

Factorising & solving a cubic

  1. Use the Factor Theorem (try factors of the constant term) to find one linear factor, e.g. $x-p$.
  2. Write $f(x) = (x-p)(ax^2+bx+c)$.
  3. Find $a$, $b$, $c$ by comparing coefficients (or substituting values).
  4. Factorise $ax^2+bx+c$ further if possible.
  5. To solve $f(x)=0$: set each factor to zero.
Worked example

Factorise and solve $x^3-6x^2+11x-6=0$.

Step 1 — try $x=1$: $1-6+11-6=0$, so $(x-1)$ is a factor.

Step 2 — divide: $$x^3-6x^2+11x-6 = (x-1)(x^2-5x+6)$$

Step 3 — factorise the quadratic: $$(x-1)(x-2)(x-3) = 0$$

Step 4 — roots: $$x=1, \ 2, \ 3$$

Exam tip: Only try values of $x$ that divide the constant term exactly — it narrows down the guessing fast.

Partial fractions

$\dfrac{P(x)}{Q(x)}$ is proper if $\deg P \lt \deg Q$, and improper if $\deg P \ge \deg Q$.

Improper fraction? Long-divide first to get a polynomial $+$ a proper fraction, then apply the steps below to the proper fraction only.
  1. Factorise the denominator $Q(x)$ completely.
  2. Match each factor to a case below.
  3. Solve for the unknowns by substituting suitable values of $x$ and/or comparing coefficients.
Denominator hasPartial fraction form
Linear factor $ax+b$$$\dfrac{A}{ax+b}$$
Repeated linear factor $(ax+b)^2$$$\dfrac{A}{ax+b} + \dfrac{B}{(ax+b)^2}$$
Quadratic factor $x^2+c^2$ (can't factorise)$$\dfrac{Ax+B}{x^2+c^2}$$
Worked example — linear factors

Split $\dfrac{x-10}{(x+4)(x-3)}$.

Set up: $$\frac{x-10}{(x+4)(x-3)} = \frac{A}{x+4} + \frac{B}{x-3}$$

Multiply through by $(x+4)(x-3)$: $x-10 = A(x-3) + B(x+4)$

Let $x=3$: $-7=7B \implies B=-1$.   Let $x=-4$: $-14=-7A \implies A=2$.

Answer: $$\frac{x-10}{(x+4)(x-3)} = \frac{2}{x+4} - \frac{1}{x-3}$$

Worked example — repeated linear factor

Split $\dfrac{2x+1}{(2x-5)^2}$.

Set up: $$\frac{2x+1}{(2x-5)^2} = \frac{A}{2x-5} + \frac{B}{(2x-5)^2}$$

Multiply through: $2x+1 = A(2x-5) + B$

Let $x=\tfrac{5}{2}$: $6=B$.   Compare $x$-coefficients: $2=2A \implies A=1$.

Answer: $$\frac{2x+1}{(2x-5)^2} = \frac{1}{2x-5} + \frac{6}{(2x-5)^2}$$
