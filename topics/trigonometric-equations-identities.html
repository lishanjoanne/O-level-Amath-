Geometry and Trigonometry

Trigonometric Equations & Identities

Principal values, the three basic identities, addition/double angle formulae, R-formulae, and — the key skill — solving trigonometric equations by finding the basic angle first. See also Trigonometric Ratios for the CAST rule this all builds on.

Key Formulas

Principal values
$$\begin{aligned} -90^\circ &\le \sin^{-1}x \le 90^\circ \\ 0^\circ &\le \cos^{-1}x \le 180^\circ \\ -90^\circ &\lt \tan^{-1}x \lt 90^\circ \end{aligned}$$
For $\sin^{-1}x$ and $\cos^{-1}x$: $-1 \le x \le 1$. For $\tan^{-1}x$: $x$ is any real number. This is the single value your calculator gives you — not necessarily the answer(s) a question wants.
Basic trigonometric identities
$$\begin{aligned} \sin^2\theta+\cos^2\theta&=1 \\ 1+\tan^2\theta&=\sec^2\theta \\ 1+\cot^2\theta&=\csc^2\theta \end{aligned}$$
From $\sin\theta=\frac{y}{r}$, $\cos\theta=\frac{x}{r}$, $\tan\theta=\frac{y}{x}$ and Pythagoras' theorem $x^2+y^2=r^2$.
Addition formulae
$$\sin(A\pm B)=\sin A\cos B \pm \cos A\sin B$$ $$\cos(A\pm B)=\cos A\cos B \mp \sin A\sin B$$ $$\tan(A\pm B)=\dfrac{\tan A\pm\tan B}{1\mp\tan A\tan B}$$
Provided in the exam formula list — no need to memorise, but know how to use them.
Double angle formulae
$$\sin 2A=2\sin A\cos A$$ $$\begin{aligned} \cos 2A&=\cos^2A-\sin^2A \\ &=2\cos^2A-1 \\ &=1-2\sin^2A \end{aligned}$$ $$\tan 2A=\dfrac{2\tan A}{1-\tan^2A}$$
Provided in the exam formula list. The three forms of $\cos 2A$ are equivalent — pick whichever matches the rest of the equation.
R-formulae
$$a\sin\theta \pm b\cos\theta = R\sin(\theta\pm\alpha)$$ $$a\cos\theta \pm b\sin\theta = R\cos(\theta\mp\alpha)$$
Where $R=\sqrt{a^2+b^2}$ and $\tan\alpha=\dfrac{b}{a}$. Not provided in the exam — you're expected to derive $R$ and $\alpha$ each time (or know the method).
R-formulae — max/min values
$$\text{Max} = R = \sqrt{a^2+b^2}$$ $$\text{Min} = -R = -\sqrt{a^2+b^2}$$
For $a\sin\theta\pm b\cos\theta$: max when $\sin(\theta\pm\alpha)=1$, min when $\sin(\theta\pm\alpha)=-1$. For $a\cos\theta\pm b\sin\theta$: max when $\cos(\theta\mp\alpha)=1$, min when $\cos(\theta\mp\alpha)=-1$.

Notes

Solving trigonometric equations — find the basic angle first

A calculator's $\sin^{-1}$, $\cos^{-1}$, $\tan^{-1}$ only ever gives the principal value — but a question usually wants every solution in a given range (e.g. $0^\circ$ to $360^\circ$). The fix is always the same:

  1. Rearrange the equation so a single trig ratio is isolated on one side (e.g. $\sin x = -\frac{1}{2}$).
  2. Find the basic angle $\alpha$ — the acute angle satisfying the positive version of the ratio: $\alpha = \sin^{-1}\left(\frac{1}{2}\right) = 30^\circ$. Ignore the sign at this stage.
  3. Use the sign of the original ratio to decide which quadrants the real solutions are in (the CAST rule).
  4. Write each solution as $180^\circ \pm \alpha$ or $360^\circ \pm \alpha$ as appropriate, then keep only the ones inside the given range.
Worked example 1

Solve $2\sin x + 1 = 0$ for $0^\circ \le x \le 360^\circ$.

Isolate: $\sin x = -\dfrac{1}{2}$

Basic angle: $\alpha = \sin^{-1}\left(\dfrac{1}{2}\right) = 30^\circ$

$\sin x$ is negative, so (by CAST) $x$ lies in Q3 or Q4 — the two quadrants above show exactly this.

$$x = 180^\circ+30^\circ = 210^\circ$$ $$\text{or} \qquad x = 360^\circ-30^\circ = 330^\circ$$

Worked example 2 — using an identity first

Solve $\cos 2\theta = 1-\sin\theta$ for $0^\circ \le \theta \le 360^\circ$.

Substitute $\cos 2\theta = 1-2\sin^2\theta$: $\quad 1-2\sin^2\theta = 1-\sin\theta$

$$2\sin^2\theta-\sin\theta=0$$ $$\Rightarrow\; \sin\theta(2\sin\theta-1)=0$$

So $\sin\theta=0$ or $\sin\theta=\dfrac{1}{2}$ — now apply the basic-angle method to each separately:

$\sin\theta=0 \Rightarrow \theta = 0^\circ, 180^\circ, 360^\circ$

$\sin\theta=\dfrac{1}{2} \Rightarrow \alpha=30^\circ$, positive in Q1 and Q2 $\Rightarrow \theta = 30^\circ, 150^\circ$

Exam tip: Reducing an equation with $\cos 2\theta$ or $\sin^2\theta$ terms to a single ratio (as in Example 2) is just algebra — the moment you're left with something like "$\sin\theta = \ldots$", go straight back to the basic-angle method. Don't try to shortcut it.
