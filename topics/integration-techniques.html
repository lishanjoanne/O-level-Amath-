Calculus

Integration Techniques

Covers all standard syllabus formulas plus the rule-by-rule "steps" from your own notes. Send over worked examples or common student mistakes and they'll be added in.

Key Formulas

Power rule
$$\int x^n \, dx = \frac{x^{n+1}}{n+1} + c$$
Valid when: $n \ne -1$.
Linear substitution (power rule)
$$\int (ax+b)^n \, dx = \frac{(ax+b)^{n+1}}{a(n+1)} + c$$
Steps: increase the power by 1 → divide by the new power → divide again by $a$ (the derivative of $ax+b$).
Reciprocal / ln
$$\begin{aligned} \int \frac{1}{x} \, dx &= \ln|x| + c \\ \int \frac{1}{ax+b} \, dx &= \frac{1}{a}\ln|ax+b| + c \end{aligned}$$
General f'(x)/f(x) form
$$\int \frac{f'(x)}{f(x)} \, dx = \ln|f(x)| + c$$
Spot this whenever the numerator is (a multiple of) the derivative of the denominator.
Exponential
$$\begin{aligned} \int e^x \, dx &= e^x + c \\ \int e^{ax+b} \, dx &= \frac{1}{a}e^{ax+b} + c \end{aligned}$$
Trigonometric
$$\begin{aligned} \int \sin x \, dx &= -\cos x + c \\ \int \cos x \, dx &= \sin x + c \\ \int \sec^2 x \, dx &= \tan x + c \end{aligned}$$
Trig with linear argument
$$\begin{aligned} \int \sin(ax+b)\,dx &= -\frac{1}{a}\cos(ax+b) + c \\ \int \cos(ax+b)\,dx &= \frac{1}{a}\sin(ax+b) + c \\ \int \sec^2(ax+b)\,dx &= \frac{1}{a}\tan(ax+b) + c \end{aligned}$$
Definite integral
$$\int_a^b f(x)\,dx = F(b) - F(a)$$
Area under a curve
$$A = \int_a^b y \, dx$$
If the curve dips below the x-axis on part of $[a,b]$, integrate each part separately and take the absolute value.

Notes

General strategy

  • Integration reverses differentiation — if unsure of a result, differentiate it back to check.
  • Always add "$+c$" for indefinite integrals — a frequently dropped mark.
  • Rewrite awkward expressions (surds, negative indices, fractions) as powers of $x$ before integrating.

Trig identities before integrating

  • There's no direct formula to integrate $\sin^2 x$ or $\cos^2 x$ — use the double-angle identities to rewrite them first: $\sin^2 x = \frac{1-\cos 2x}{2}$, $\cos^2 x = \frac{1+\cos 2x}{2}$.
  • Example: $\int \sin^2 x \, dx = \int \frac{1-\cos 2x}{2}\,dx = \frac{x}{2} - \frac{\sin 2x}{4} + c$.
  • Watch for $\sin^2 x + \cos^2 x = 1$ and $\tan^2 x = \sec^2 x - 1$ too — both can simplify an integrand before you integrate.
Exam tip: Don't forget the $\frac{1}{a}$ factor when integrating a function of $(ax+b)$ — it's easy to integrate as if $a = 1$.
